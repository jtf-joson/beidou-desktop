## dsh-tools schema DSL 三条硬约束(不变)
1. parameters 全必填(required: true;可选参数用 required: false + 默认值)
2. output.schema 是 DSL 非原生 JSON Schema(additionalProperties 显式 / 属性逐个 required)
3. esbuild bundle 是必需的(dsh ESM loader 不认 TS 源码的扩展名 import;bundle 后引用稳定 JS 产物 = 评审 P0-3 要求)
