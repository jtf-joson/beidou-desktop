## dsh-tools schema DSL 学习(Phase 3 移植工具的硬约束)

1. **parameters 不支持可选参数**:所有参数必须 `required: true`(不支持 `required: false` / `optional`)。
2. **output.schema 是同一个 DSL,不是原生 JSON Schema**:object 必须显式 `additionalProperties: true|false`;嵌套属性各自 `required: true`;不支持 JSON Schema 的 `required: []` 数组语法。
3. 错误信息质量高:violations 数组精确定位 `parameters.echo.required` / `schema.additionalProperties`。

**对 Phase 3 的影响**:core 工具的可选参数(dims?/timeRange?/limit? 等)在 dsh 端要重新设计:
- 方案 A:合并入一个 JSON string 参数(模型传 JSON 字符串,内部解析)
- 方案 B:dsh 端全部必填、给空对象/空数组的默认约定
- 方案 C:查 dsh-tools 是否有 union/optional 语法待确认(cookbook 的 oneOf 分支存在,待读)
