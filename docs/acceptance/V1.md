## dsh-tools DSL 完整约束(7 条)
1. 全参数 required:true(不支持 false)
2. output.schema 是 DSL 非原生 JSON Schema
3. object 参数必须显式 additionalProperties
4. output 全属性必须 required(含 error → 成功时空串)
5. Cordis 不 await async apply(同步 apply + void async + throw on error)
6. dsh ESM 不认 TS 源码 import(必须 esbuild bundle)
7. 未命中路由 = 拒绝(fail-closed)
