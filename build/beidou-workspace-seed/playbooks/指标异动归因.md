# 指标异动归因 Playbook(示例 SOP)

适用:用户问「XX 为什么涨/跌」「帮我归因/诊断 XX」。

## 步骤
1. **确认口径**:search_semantics 确认指标;时间范围不明先 clarify。
2. **跑诊断**:diagnose_metric(metricName, timeRange)拿结构化结果(总量对比/异常/贡献拆解)。
3. **查背景**:search_knowledge 检索业务解释(交付节奏/配置变更/季节因素)。
4. **出报告**,结构:
   - 结论(指标、本期/基期、变化幅度、是否异常)
   - 归因(Top 贡献维度与值,给贡献百分比)
   - 业务解释(知识库证据;无证据写「待业务确认」)
   - 建议动作(继续观察/下钻验证/业务确认)
5. **红线**:数字必须来自工具结果;归因≠因果,必须注明。

> Playbook 即文件:业务分析方法沉淀到本目录,Agent 做正式分析前会读取(read_playbook)。
